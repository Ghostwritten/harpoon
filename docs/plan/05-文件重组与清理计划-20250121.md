## 关于 Makefile

### 依赖说明

**Makefile 本身无额外依赖**：

- `make` 命令在大多数 Unix/Linux/macOS 系统上默认安装
- Windows 上可以通过以下方式获得：
  - WSL (Windows Subsystem for Linux)
  - Git for Windows（通常包含 make）
  - Chocolatey: `choco install make`
  - 或者直接使用 `build.sh`（通过 Git Bash 或 WSL）

### Makefile 设计

**目标**：提供简洁的命令包装，同时保持向后兼容

**建议的 Makefile 内容**：

```makefile
.PHONY: build build-all build-current clean help

# 默认目标
help:
	@echo "Available targets:"
	@echo "  make build        - Build for current platform"
	@echo "  make build-all    - Build for all platforms"
	@echo "  make clean        - Clean build artifacts"
	@echo "  make test         - Run tests"
	@echo "  make install      - Install to /usr/local/bin"

build:
	@./build.sh current

build-all:
	@./build.sh all

clean:
	@./build.sh clean

test:
	@go test ./...

install: build
	@sudo cp dist/hpn-$(shell uname -s | tr '[:upper:]' '[:lower:]')-$(shell uname -m | sed 's/x86_64/amd64/') /usr/local/bin/hpn
	@sudo chmod +x /usr/local/bin/hpn
```

**优点**：

- 提供标准化的构建接口
- 跨平台兼容（通过 build.sh）
- 不强制依赖 make（仍可直接使用 build.sh）
